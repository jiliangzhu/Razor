# Migration v1.4.0 (from v1.3.2a)

目标：支持多腿与负风险策略审计，同时保持 Phase 1 dry-run 约束不变。

## 1) 版本变更
- `SCHEMA_VERSION`: `1.3.2a` → `1.4.0`
- `schema_version.json`：
  - `snapshots.csv`: `v1` → `v2`
  - `shadow_log.csv`: `v5` → `v6`

## 2) CSV 变更
### snapshots.csv
- 新增列：`legs_json`（追加在最后）
- 用途：完整保存所有腿的 `market_id/token_id/best_bid/best_ask/depth3_usdc`

### shadow_log.csv
- 新增列：`legs_json`（位于 `dump_slippage_assumed` 与 `notes` 之间）
- 用途：完整保存所有腿的 `market_id/token_id/side/limit_price/qty/best_bid_at_signal/best_ask_at_signal`

## 3) 策略扩展
- `strategy` 增加：`multi`、`neg_risk`
- `legs_n` 不再限制为 2/3（仍以 `legs_json` 记录全量腿）

## 4) 兼容建议
- 读取 CSV 必须按 header 名称定位列（不要依赖列顺序）
- 旧版工具若忽略 `legs_json`，仍可依赖前 3 腿固定列进行粗粒度分析
